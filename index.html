        About LemonLoader Web
        
      
        LemonLoader Web is a free, unofficial tool for Meta Quest headsets. It patches Unity games so they can load LemonLoader mods, and it manages those mods, all from your browser over a USB cable. There is nothing to install on your headset or your computer.
        
      
        Everything runs over WebUSB. Your game files move only between your browser and your headset, and the site never uploads them anywhere.
        

      
        What you can do
        
      
          
        
        • Find the IL2CPP Unity games on your headset that LemonLoader can patch.
          • 
        
        • Patch a game and install the patched copy.
          • 
        
        • Add, remove, name, enable and disable mods for patched games.
          • 
      
        

      
        What you need
        
      
          
        
        • A Quest 1, Quest 2, Quest 3, Quest 3S or Quest Pro with developer mode turned on.
          • 
        
        • A USB cable that carries data, not just power.
          • 
        
        • Chrome or Edge, since other browsers don't support WebUSB.
          • 
      
        

      
        Good to know
        
      
        Installing a patched game replaces the original, which can erase its save data. LemonLoader Web is an independent project and isn't affiliated with the LemonLoader or MelonLoader teams. It's open source on GitHub, and the patcher is based on the LemonLoader installer.
        
    
        
    
        
      
        Frequently asked questions
        

      
        My headset won't connect. What should I check?
        
      
        Work through these in order:
        
      
          
        
        • Developer mode: it has to be turned on for your headset in the Meta Horizon phone app (you may need a free developer account). Without it, the headset never shows up in the list.
          • 
        
        • USB debugging prompt: after you choose Connect headset, put the headset on and choose Allow. If you chose Don't allow, unplug and replug the cable and try again.
          • 
        
        • Cable and port: use a cable that carries data, not a charge-only one, and plug the headset into the device that is showing this page.
          • 
        
        • Other programs: close other ADB tools on your computer, since only one program can use the connection at a time.
          • 
        
        • Browser: use Chrome or Edge. Firefox and Safari don't support WebUSB.
          • 
      
        

      
        Why isn't my game listed on the Patch tab?
        
      
        LemonLoader only works with Unity games built with IL2CPP. Games made with other engines, or with Unity's older Mono setup, aren't listed. A game also won't appear in the Mods tab until it has been patched and launched once.
        

      
        The patch failed. What went wrong?
        
      
        There are two common causes. The first is a problem on this website or with your setup: reload the page and try again, keep the headset awake and plugged in, and make sure it has free storage of at least the size of the game, because patching makes a full copy. The second is the game itself: some games protect or obfuscate their files, which can stop patching or stop LemonLoader from working. If the error mentions the Unity version or a missing file, this is the likely cause, and that game may not be patchable. If the same error keeps happening across several games, please report it on the project's GitHub page and include the error text.
        

      
        The game takes a long time to load after patching. Is it broken?
        
      
        Probably not. The first launch of a patched game is slow, sometimes several minutes, because LemonLoader is setting itself up for that game. Let it finish and don't force close it. The first launch can also crash, so if it does, open the game again. Later launches are much faster.
        

      
        Will patching a game erase my saves?
        
      
        It can. The patched copy is signed differently from the original, so Android has to remove the original game before installing it, and that can delete the game's local save data. Games that keep progress in an online account are not affected.
